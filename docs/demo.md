# Demo Script

Two flavors — a 3-minute prelim demo and a 3–5-minute finalist pitch. Rehearse both. Pre-cache fallback blurbs so the demo never stalls on Claude latency.

## 3-minute prelim demo

### `0:00 – 0:20` — Hook
> *"Singapore has the best mala in the world outside of Chengdu. But ask any couple their first-date horror story and it's 'we couldn't agree on where to eat.' MalaBook fixes that. We match people by **how** they eat málà."*

### `0:20 – 1:30` — Live demo
- Open onboarding: *"I'm a Level 4 dry-pot person, I love lotus root, beef tripe, and enoki."*
- Submit → match feed appears with top cards
- Read out one AI-generated blurb
- Tap into a match → AI suggests Chuan's Kitchen with reasoning
- *"Two taps. AI did the matchmaking and booked the vibe."*

### `1:30 – 2:15` — How it works
- Show the 14-dim flavor vector encoding
- Show the two Claude prompts
- Mention: cosine sim for retrieval, LLM for the human-readable layer — a classic **embeddings + generative** pattern

### `2:15 – 3:00` — Roadmap & ask
- Long-term: native iOS/Android, real-time chat, OpenTable, expansion to other cuisines
- Ask judges: feedback on matching dimensions, ideas for monetisation

## Finalist presentation (6:15 – 7:15 PM, if finalist)

3–5 minutes on stage. Tightened version:

| Time | Beat |
|---|---|
| `0:00 – 0:20` | Hook — same as prelim |
| `0:20 – 1:30` | Live demo: onboarding → matches → date suggestion |
| `1:30 – 2:15` | "How it works": flavor vector + 2 Claude prompts. Show code briefly. |
| `2:15 – 3:00` | Roadmap + ask: native app, real chat, OpenTable, other cuisines |

**Backup plan if live demo fails on stage:** 60-second screen recording on laptop, played muted while you narrate.

**Between 5:00 PM and 6:15 PM:** rest, hydrate, eat. Don't keep tweaking — you'll only break things.
